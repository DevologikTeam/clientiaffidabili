# Design System Components

Sprint M1-S ha trasformato il blueprint in una prima libreria UI riutilizzabile.

Componenti disponibili:

- `Alert`
- `Badge`
- `Button`
- `Card`
- `Checklist`
- `DataTable`
- `EmptyState`
- `Field`
- `KeyValueList`
- `PageHero`
- `PriceCard`
- `ProgressBar`
- `SectionHeader`
- `StatCard`
- `StatusPill`
- `Stepper`
- `TrustNotice`

Regole obbligatorie:

1. Usare classi `ca-*` per ogni componente del design system.
2. Una sola CTA primaria per blocco decisionale.
3. Stati sempre testuali, mai affidati solo al colore.
4. Ogni form field deve avere label visibile, help o errore contestuale quando serve.
5. Nessun dato demo nei flussi reali: le pagine demo devono restare esplicitamente marcate.
