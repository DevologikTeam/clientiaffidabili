# M9-P — Source Notes

## Fonti usate come baseline

- OWASP Top Ten Web Application Security Risks: baseline per rischi applicativi web. Nota rilevante: la versione corrente rilasciata indicata dal sito OWASP e' la Top Ten 2025.
- OWASP API Security Top 10 2023: baseline per API risk, in particolare API1 Broken Object Level Authorization, API4 Unrestricted Resource Consumption e API10 Unsafe Consumption of APIs.
- GDPR / Regulation (EU) 2016/679: baseline privacy, minimizzazione, privacy by design, accountability, sicurezza del trattamento e data breach notification.
- NIS2 / Directive (EU) 2022/2555: baseline prudente per gestione rischio cybersecurity, incident handling, continuita' e supply-chain, da confermare nel perimetro legale effettivo.

## Nota progetto

Queste fonti non sostituiscono consulenza legale o pentest. Servono per trasformare requisiti generali in controlli concreti di prodotto, codice, deploy e QA.
