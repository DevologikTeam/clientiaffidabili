# Competitor Notes — M2-A

## Openapi

Openapi comunica:

- marketplace ampio di API certificate;
- oltre 400 servizi;
- categorie Business Information, ID & Trust, Digital Transformation, Real Estate, Persona, Automotive e altre;
- developer documentation, GitHub e Postman;
- prezzi trasparenti e assenza di canoni annuali;
- posizionamento “API Made Simple”.

Implicazione: ClientiAffidabili.it non deve competere sulla quantità di API, ma trasformare API selezionate in flussi decisionali facili.

## Cerved

Cerved comunica:

- autorevolezza enterprise;
- decisioni migliori per crescita sostenibile;
- aree Smart Business, Smart Commerce, Fraud & Compliance, Smart Lending, Credit Management, Rating Agency e Physical Assets.

Implicazione: differenziarsi con semplicità, checkout rapido e focus PMI.

## CRIF

CRIF comunica:

- information;
- intelligence;
- platforms;
- outsourcing;
- mercati verticali come banche, assicurazioni, imprese, telco, energy/utility;
- soluzioni per AI transformation, gestione credito, antifrode, pricing, underwriting.

Implicazione: evitare posizionamento troppo enterprise e lavorare su use case chiari e acquistabili.

## Creditsafe

Creditsafe comunica:

- report aziende italiane e internazionali;
- monitoraggio incluso;
- esperienze di pagamento;
- API e integrazioni REST;
- pacchetti commerciali;
- prova gratuita.

Implicazione: utile benchmark per report, monitoraggio e fiducia; ClientiAffidabili.it deve puntare a checkout immediato e pacchetti piccoli.

## Differenziazione sintetica

| Player | Forza | Spazio per ClientiAffidabili.it |
|---|---|---|
| Openapi | Ampiezza API e developer ecosystem | UX verticale no-code per decisioni B2B |
| Cerved | Autorevolezza enterprise | Acquisto rapido, semplicità PMI |
| CRIF | Dati, intelligence, piattaforme | Micro-controlli operativi e checkout |
| Creditsafe | Report e monitoraggio | Pacchetti piccoli, copy prudente, report decisionale |
