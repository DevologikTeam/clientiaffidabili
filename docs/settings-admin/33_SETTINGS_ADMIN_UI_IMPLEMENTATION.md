# Settings Admin UI Implementation

## Route
`/admin/settings`

## Sezioni
- Overview stato piattaforma.
- Kill switch acquisti.
- Namespace settings.
- Tabella settings.
- Error ledger.

## UX rules
- Niente segreti in chiaro.
- Stato e prossima azione sempre visibili.
- Copy operativo: cosa e' bloccato, perche', impatto e prossima azione.
- Le azioni sensibili richiederanno reason modal nello sprint di hardening UI successivo.
