# Service selection MVP

## Principio di selezione

Ogni servizio deve superare 6 filtri:

1. coerente con il dominio ClientiAffidabili.it;
2. capibile da una PMI senza competenze API;
3. acquistabile in self-service;
4. margine sufficiente dopo fee e assistenza;
5. rischio privacy/compliance gestibile;
6. output trasformabile in report utile.

## Catalogo pubblico MVP

### 1. Verifica azienda essenziale

**Per chi:** freelance, microimprese, amministrazione, commerciale.  
**Problema:** “Questa azienda esiste ed è coerente con i dati che mi ha dato?”  
**Output:** scheda sintetica, dati identificativi, stato, recapiti business, nota limiti.  
**Prezzo:** €14,90 + IVA.

### 2. Check Affidabilità Pro

**Per chi:** PMI B2B, e-commerce B2B, agenzie, fornitori.  
**Problema:** “Posso vendere, spedire, concedere pagamento o iniziare collaborazione?”  
**Output:** score, segnali rischio, negatività, soggetti collegati, prossima azione.  
**Prezzo:** €24,90 + IVA.

### 3. Affidabilità Pro + Bilancio

**Per chi:** decisioni di valore più alto.  
**Problema:** “Mi serve un approfondimento economico-finanziario in più.”  
**Output:** report Pro + bilancio disponibile/estratto + nota interpretativa.  
**Prezzo:** €34,90 + IVA.

### 4. KYB Compliance

**Per chi:** aziende con onboarding partner/fornitori più sensibile.  
**Problema:** “Devo capire assetti, soggetti rilevanti e segnali compliance.”  
**Output:** assetti, stakeholder, titolare effettivo se disponibile, AML/PEP/Sanctions dove applicabile.  
**Prezzo:** €49,90 + IVA.

### 5. Verifica IBAN

**Per chi:** amministrazioni, fornitori, contabilità.  
**Problema:** “Voglio ridurre errori prima di registrare un IBAN.”  
**Output:** validità tecnica, banca/BIC se disponibile, area SEPA, esito operativo.  
**Prezzo:** €4,90 + IVA.

### 6. Verifica email e telefono

**Per chi:** CRM, lead generation, onboarding.  
**Problema:** “I contatti inseriti sono utilizzabili o sporchi?”  
**Output:** validità, raggiungibilità tecnica, stato operativo.  
**Prezzo:** €4,90 + IVA.

## Catalogo interno non pubblico MVP

| Servizio | Stato | Motivo |
|---|---|---|
| Report Azienda Top | Assistito | Costo alto e tempi lunghi. |
| Visure Centrale Rischi | Assistito/futuro | Tempi lunghi, forte aspettativa cliente, rischio supporto. |
| Documenti catastali | Futuro verticale | Coerente solo se nasce verticale Real Estate. |
| Pratiche persona/CAF | Escluso | Non coerente con MVP. |

| Firma/PEC/Fatturazione | Futuro B2B ops | Può diventare add-on, non core iniziale. |

## Ordine di visibilità pubblica

1. Check Affidabilità Pro.
2. Verifica azienda essenziale.
3. KYB Compliance.
4. Verifica IBAN.
5. Verifica email e telefono.
6. Affidabilità Pro + Bilancio come add-on/suggerimento contestuale.

## Regola UX

Il catalogo non deve essere una tabella tecnica. Deve partire da domande:

- “Devo fidarmi di un nuovo cliente?”
- “Sto scegliendo un fornitore importante?”
- “Devo controllare dati di pagamento?”
- “Devo fare un controllo più prudente su partner o assetti?”

Solo dopo mostra nome servizio, prezzo e tempi.
