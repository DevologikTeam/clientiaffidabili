# Public service card copy deck

## Regola copy

Ogni servizio deve essere presentato come supporto alla decisione, non come garanzia di affidabilità. Il copy deve essere concreto, prudente e commerciale.

## Verifica azienda essenziale

**Titolo:** Verifica azienda essenziale  
**Sottotitolo:** Controlla i dati principali di un'azienda prima di procedere.  
**Prezzo:** €14,90 + IVA  
**Tempo:** pochi minuti

**Bullet valore:**

- dati identificativi e stato attività;
- primo quadro sintetico per uso professionale;
- utile prima di preventivi, forniture o pagamenti differiti.

**CTA:** Avvia verifica essenziale  
**Nota limiti:** Non sostituisce un'istruttoria completa o una valutazione legale/creditizia.

## Check Affidabilità Pro

**Titolo:** Check Affidabilità Pro  
**Sottotitolo:** Raccogli segnali utili prima di vendere, spedire o concedere credito.  
**Prezzo:** €24,90 + IVA  
**Tempo:** pochi minuti

**Bullet valore:**

- score sintetico e segnali disponibili;
- dati aziendali e soggetti collegati;
- prossima azione consigliata per il tuo team.

**CTA:** Avvia Check Pro  
**Nota limiti:** Il report riduce decisioni al buio, ma non garantisce pagamenti o assenza di rischio.

## Affidabilità Pro + Bilancio

**Titolo:** Affidabilità Pro + Bilancio  
**Sottotitolo:** Aggiungi un approfondimento economico-finanziario quando la decisione pesa di più.  
**Prezzo:** €34,90 + IVA  
**Tempo:** da pochi minuti, se il documento è disponibile

**Bullet valore:**

- include i segnali del Check Pro;
- aggiunge dati di bilancio disponibili;

**CTA:** Avvia Pro + Bilancio  
**Nota limiti:** La disponibilità e l'aggiornamento dei documenti dipendono dalle fonti ufficiali disponibili.

- cliente sicuro;
- pagherà sicuramente;
- affidabilità garantita;
- indagine personale;
- controllo definitivo;
- zero rischi;
- database completo;
