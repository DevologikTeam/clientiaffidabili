# Backlog MVP

## Must have

- Landing pubblica con posizionamento decisionale.
- Catalogo servizi MVP.
- Wizard verifica azienda.
- Riepilogo checkout.
- Stripe Checkout adapter.
- Ordine e pagamento.
- Provider adapter con mock e feature flag.
- Report azienda normalizzato.
- Dashboard storico verifiche.
- Audit log.
- Legal pages placeholder da finalizzare.
- Docker Compose e deploy Coolify.

## Should have

- Download PDF.
- Email report pronto.
- Admin catalogo/prezzi.
- Retry provider.
- Validazioni avanzate CF/IBAN.
- Export CSV.

## Could have

- Monitoraggio azienda.
- Piani team.
- API partner.
- Nexi/Mollie adapter.
- MFA.

## Won't have nel primo MVP

- Marketplace di tutti gli endpoint.
- Scoring proprietario avanzato addestrato.
- Automazioni complesse.
- White label per partner.
- SLA enterprise.
