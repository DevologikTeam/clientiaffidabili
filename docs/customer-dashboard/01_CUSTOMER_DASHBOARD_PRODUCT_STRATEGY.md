# Customer Dashboard — Product Strategy

## Posizionamento area cliente

L'area cliente deve completare il ciclo di valore di ClientiAffidabili.it:

`scopro il servizio -> scelgo verifica -> pago -> attendo elaborazione -> leggo report -> decido prossima azione -> recupero storico`

La dashboard non deve diventare un gestionale complesso. Deve essere una superficie semplice, rassicurante e operativa per PMI, amministratori, uffici acquisti, agenzie, consulenti e operatori commerciali.

## Promessa utente

> Tieni sotto controllo le verifiche richieste, leggi i report pronti e capisci subito se serve un'azione.

## Job-to-be-done principali

| Utente | Bisogno | Output dashboard |
|---|---|---|
| Titolare PMI | Capire se fidarsi di un nuovo cliente/fornitore | Report pronto, sintesi, limiti, prossima azione prudente |
| Amministrazione | Recuperare verifica acquistata e fattura | Storico ordini, stato pagamento, fattura pending/issued |
| Commerciale | Verificare più prospect | Lista verifiche, filtri per azienda/stato, confronto base |
| Consulente | Documentare la verifica svolta per un cliente | Report scaricabile in futuro, evidenze e fonti |
| Operatore interno | Gestire richieste bloccate | Stati chiari e canale supporto, senza dati tecnici |

## Moduli dashboard candidati

1. **Riepilogo operativo**
   - verifiche in corso;
   - report pronti;
   - azioni richieste;
   - pagamenti/fatture da completare.

2. **Le mie verifiche**
   - lista verifiche;
   - stato leggibile;
   - azienda/soggetto verificato;
   - servizio acquistato;
   - data richiesta;
   - data report;
   - CTA contestuale.

3. **Report recenti**
   - ultimi report pubblicati;
   - livello di attenzione;
   - fonti principali;
   - data snapshot;
   - avviso sui limiti.

4. **Ordini e fatture**
   - ordine;
   - importo;
   - metodo pagamento;
   - stato pagamento;
   - stato fattura;
   - ricevuta/fattura quando disponibile.

5. **Centro notifiche/task**
   - richiesta dati mancanti;
   - pagamento non completato;
   - report pronto;
   - review manuale in corso;
   - servizio non disponibile.

6. **Supporto**
   - richiesta assistenza su ordine/report;
   - domande frequenti;
   - tempi di evasione dichiarati;
   - escalation interna.

## Differenziazione competitiva

Molti portali di dati vendono report o API con esperienza tecnica o transazionale. ClientiAffidabili.it deve differenziarsi con:

- linguaggio orientato alla decisione;
- stato operativo chiaro;
- report non grezzo;
- storico leggibile;
- limiti trasparenti;
- supporto al processo, non solo download.

## Misure di successo

- riduzione richieste supporto su stato ordine/report;
- aumento download/lettura report completati;
- aumento acquisti ripetuti;
- riduzione checkout abbandonati post-login;
- tempo medio per ritrovare un report sotto 30 secondi;
- nessun reclamo causato da claim troppo assoluti.
