# Copilot Admin UI Implementation

## Route

```text
/admin/openai-copilot
```

## Componenti

- `CopilotStatusPanel`;
- `CopilotUseCaseGrid`;
- `CopilotDraftQueue`;

## UX

La pagina comunica chiaramente:

- OpenAI e' disabilitato di default;
- le risposte sono bozze;
- ogni azione sensibile resta manuale;
- settings e budget sono governati da admin.
