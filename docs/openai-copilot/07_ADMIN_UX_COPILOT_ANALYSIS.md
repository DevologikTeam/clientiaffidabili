# Admin UX Copilot Analysis

## Superfici admin candidate

### CMS SEO/GEO

CTA possibili:

- Migliora titolo SEO;
- Suggerisci meta description;
- Genera FAQ;
- Controlla claim rischiosi;
- Migliora risposta breve GEO.

### CRM/Supporto

CTA possibili:

- Riassumi messaggio;
- Suggerisci priorita';
- Prepara bozza risposta;
- Estrai azioni richieste.

### Error Ledger

CTA possibili:

- Riassumi errore;
- Raggruppa errori simili;
- Suggerisci causa probabile;
- Prepara nota tecnica per sviluppatore.

### Admin Operations

CTA possibili:

- Spiega stato operativo;
- Suggerisci prossima azione sicura;
- Crea bozza nota interna.

## Pattern UX

- bottone secondario, non primario;
- pannello laterale con input redatto;
- preview output;
- indicatori: modello, prompt version, dati rimossi;
- CTA: Usa bozza, Modifica, Rigenera, Scarta;
- audit visibile nelle timeline.

## Stati UI

- OpenAI disabilitato;
- use case non autorizzato;
- budget esaurito;
- dati insufficienti;
- redaction failed;
- safety blocked;
- output pronto;
- approvato;
- scartato.

## Copy UX

Usare copy prudente:

- "Suggerimento AI";
- "Bozza da verificare";
- "Controlla prima di pubblicare";
- "Dati sensibili rimossi";
- "Azione non automatica".
