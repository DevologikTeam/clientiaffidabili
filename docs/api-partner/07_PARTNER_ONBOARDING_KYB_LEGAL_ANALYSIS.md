# 07 — Partner Onboarding, KYB & Legal Analysis

## Onboarding partner

Il partner non deve poter accedere alla produzione solo registrandosi. Serve un flusso approvativo:

1. richiesta accesso partner;
2. dati aziendali e referenti;
3. descrizione use case;
4. accettazione termini partner;
5. verifica interna;
6. accesso sandbox;
7. richiesta production;
8. review tecnica/compliance;
9. attivazione live.

## Dati minimi partner

- Ragione sociale;
- P.IVA/VAT;
- paese;
- email referente tecnico;
- email referente amministrativo;
- sito web;
- use case;
- volume previsto;
- categorie clienti serviti;
- richiesta API o solo reseller.

## Review production

La review deve verificare:

- use case lecito;
- contratti/termini accettati;
- IP allowlist se richiesta;
- webhook configurati correttamente;
- piano/crediti attivi;
- limiti prodotti;
- support owner interno;
- rischi compliance.

## Documenti legali futuri

- Partner Terms;
- API Terms;
- Data Processing Addendum se necessario;
- Acceptable Use Policy;
- SLA/Support terms per piani alti;
- Reseller commercial terms;
- Data retention addendum.

## Decisione MVP

Legal pack partner in bozza, ma produzione partner bloccata finché non validata legalmente.
