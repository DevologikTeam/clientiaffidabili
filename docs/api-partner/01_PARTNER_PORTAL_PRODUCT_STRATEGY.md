# 01 — Partner Portal Product Strategy

## Posizionamento

Il portale partner deve trasformare ClientiAffidabili.it da prodotto direct-to-customer a piattaforma B2B2B controllata. Non è un marketplace API aperto: è un canale selettivo per partner che vogliono integrare o rivendere verifiche affidabilità.

## Promessa commerciale

> Porta verifiche aziendali, controlli KYB e report affidabilità nei tuoi flussi, senza costruire integrazioni complesse con provider dati, pagamenti e reportistica.

La promessa non deve dire “dati sempre certi” o “rischio eliminato”. Deve restare prudente: report e verifiche supportano decisioni operative, non sostituiscono valutazioni legali/finanziarie.

## Partner journey

1. Scopre il programma partner.
2. Richiede accesso.
3. Viene approvato manualmente.
4. Accede alla sandbox.
5. Genera API key test.
6. Prova esempi API e webhook.
7. Acquista crediti o piano.
8. Richiede produzione.
9. Supera review compliance.
10. Attiva chiavi live.
11. Monitora consumi, report, errori e crediti.

## Principi prodotto

- prima valore operativo, poi API;
- self-service solo quando sicuro;
- ogni costo provider deve essere coperto da credito, pagamento o piano;
- ogni accesso dati deve essere autorizzato a livello oggetto;
- ogni azione sensibile deve lasciare audit;
- ogni partner deve vedere limiti, crediti, errori e prossima azione.

## Offerta MVP

- Partner dashboard;
- API key sandbox;
- API documentation;
- simulatore sandbox;
- webhook endpoint configuration;
- usage ledger;
- credit wallet;
- richiesta produzione;
- admin approval queue.

## KPI da monitorare

- partner approvati;
- partner sandbox attivi;
- API key generate;
- chiamate sandbox per partner;
- conversione sandbox → production;
- crediti acquistati;
- consumi provider coperti;
- errori API per endpoint;
- margine per partner;
- report pubblicati tramite API;
- richieste supporto developer.
