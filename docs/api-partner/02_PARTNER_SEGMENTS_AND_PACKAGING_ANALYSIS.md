# 02 — Partner Segments and Packaging Analysis

## Segmenti prioritari

### Software house / gestionali

Hanno bisogno di API stabili, documentazione chiara, ambiente sandbox e supporto tecnico. Valore: integrazione ricorrente nei loro prodotti.

### Agenzie commerciali B2B

Hanno bisogno di pacchetti crediti, report, dashboard e storico. Spesso non hanno bisogno di API production immediata.

### Studi professionali

Hanno bisogno di rivendere o acquistare report per clienti. Richiedono copy prudente, fatture, documenti e assistenza.

### Marketplace/procurement

Richiedono KYB, monitoraggio fornitori, webhook e workflow controllati. Alto potenziale ma alto rischio compliance.

## Packaging consigliato

| Pacchetto | Focus | Funzioni |
|---|---|---|
| Reseller Starter | vendita assistita | dashboard, crediti, report, no API live automatica |
| Developer Sandbox | integrazione test | API test, docs, webhook test, dati simulati |
| API Partner Pro | API live controllata | key production, rate limit, webhook, supporto |
| Enterprise | integrazioni complesse | limiti dedicati, contratto, supporto e SLA |

## Regola importante

Non vendere “API illimitate”. Ogni piano deve avere limiti, crediti o fair usage misurabile.
