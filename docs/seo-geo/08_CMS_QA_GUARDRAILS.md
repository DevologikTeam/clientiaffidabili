# QA CMS SEO/GEO

## Gate documento
Ogni pagina pubblicabile deve avere:
- slug valido;
- titolo non vuoto;
- meta title;
- meta description;
- excerpt;
- target keyword;
- intento di ricerca;
- body con almeno 3 sezioni;
- sezione limiti/garanzia operativa;
- CTA coerente.

## Gate claim
La QA deve bloccare claim assoluti, promesse di risultato e linguaggio investigativo non coerente con un servizio B2B decision-support.

## Gate tecnico
- editor renderizzato client-side;
- SSR safe;
- nessun raw HTML esterno non sanitizzato in produzione;
- versioning contenuto;
- pubblicazione auditata;
- redirect plan se slug cambia.

## Gate SEO/GEO
- title massimo consigliato 60 caratteri;
- description massimo consigliato 160 caratteri;
- H1 unico;
- FAQ concise;
- contenuto utile e non generico;
- no duplicazione massiva tra pagine.
