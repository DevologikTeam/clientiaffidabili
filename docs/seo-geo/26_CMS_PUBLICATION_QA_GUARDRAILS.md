# CMS Publication QA Guardrails

## Blocchi pubblicazione

Una guida non deve essere pubblicata se contiene claim vietati, se manca risposta GEO, se manca la sezione limiti o se non ha un collegamento ad almeno una prossima azione.

## Claim vietati

- promessa di assenza totale del rischio;
- promessa di incasso certo;
- promessa di solvibilità certa;
- claim di infallibilità;
- linguaggio investigativo o aggressivo.

## Checklist editoriale minima

- H1 chiaro;
- meta title e description coerenti;
- risposta breve utile;
- almeno 2 FAQ;
- limiti e garanzia operativa;
- CTA contestuale;
- link correlati;
- nessun dato personale o raw provider.
