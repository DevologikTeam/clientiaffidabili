# M14B-P / M14B-S Readiness Checklist

## Prima di M14B-P

- [x] Definire topic cluster.
- [x] Definire intenti primari e secondari.
- [x] Definire struttura pagina.
- [x] Definire copy approvato per garanzia/limiti.
- [x] Definire governance CMS.
- [x] Definire metriche e iterazione.
- [x] Definire claim vietati.

## M14B-P deve produrre

- template pagina guida;
- componenti UI per guide educative;
- content briefs per prime 5 pagine;
- schema metadata per CMS;
- workflow review/publish;
- checklist SEO/GEO in UI admin;
- regole di internal linking;
- regole CTA e conversione.

## M14B-S deve produrre

- componenti pubblici guide;
- miglioramento rendering `/guide/[slug]`;
- blocchi content model nel CMS;
- checklist publish rafforzata;
- seed bozze per le prime pagine;
- sitemap/robots coerenti;
- QA antiregressione e claim guard.

## Gate di qualita'

Nessuna pagina educativa deve andare live se manca:

- blocco limiti;
- garanzia operativa;
- CTA corretta;
- metadata;
- review umana;
- controllo claim vietati;
- assenza PII;
- stato `published` esplicito.
