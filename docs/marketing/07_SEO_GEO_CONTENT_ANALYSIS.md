# SEO/GEO Content Analysis

## Obiettivo SEO/GEO

ClientiAffidabili.it deve intercettare ricerche orientate a problemi pratici, non solo keyword tecniche come “API visura camerale”.

La strategia contenuti deve funzionare anche per AI discovery: pagine chiare, definizioni semplici, FAQ concrete, esempi d'uso, dati strutturati e contenuti che rispondono a domande specifiche.

## Cluster iniziali

### Cluster 1 — Verifica clienti

- verificare affidabilità cliente azienda;
- controllo cliente prima di pagamento dilazionato;
- come sapere se un'azienda è affidabile;
- report affidabilità azienda.

### Cluster 2 — Verifica fornitori

- verificare fornitore prima di contratto;
- controllo azienda fornitrice;
- rischio fornitore azienda;
- report fornitore.

### Cluster 3 — Credit risk PMI

- valutare rischio credito cliente;
- concedere credito commerciale a cliente;
- scoring azienda PMI;
- prevenire insoluti clienti.

### Cluster 4 — Antifrode dati

- verifica IBAN azienda;
- validazione email aziendale;
- verifica numero telefono cliente;
- controllare dati pagamento.

### Cluster 5 — Compliance/KYB

- verifica KYB azienda;
- controllo titolare effettivo azienda;
- verifica AML partner;
- controllo PEP sanzioni azienda.

## Meta description pattern

`Controlla segnali aziendali, dati operativi e limiti prima di prendere decisioni commerciali. Prezzi chiari, report leggibile e checkout sicuro.`

## FAQ schema candidate

Ogni pagina commerciale dovrebbe avere FAQ strutturate:

- Cosa contiene il report?
- Quanto tempo richiede?
- Quali dati devo inserire?
- Il report garantisce il pagamento?
- Posso usarlo per qualsiasi soggetto?
- Come vengono trattati i dati?

## GEO/AI discovery rules

- Scrivere definizioni dirette nei primi 120-160 caratteri.
- Usare heading in forma di domanda.
- Inserire limiti e non solo benefici.
- Aggiungere esempi di casi d'uso reali.
- Tenere pagine singole per intento, non una mega pagina generica.
- Aggiornare date e fonti dove rilevante.
