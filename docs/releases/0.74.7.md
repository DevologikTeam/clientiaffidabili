# Release 0.74.7 — Web Build Static Guards Patch 7

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next emerso durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime/build

Errore corretto:

```text
Type '"informational"' is not assignable to type 'EducationIntent'.
```

Intervento:

- `EducationIntent` ora include anche `informational`.
- `seo-cms-runtime` mappa `informational` verso `SeoSearchIntent` `informational`.
- La correzione evita il failure sulle pagine guida SEO/GEO `credit-scoring-azienda-significato` e `kyb-aml-controlli-azienda`.
- Versioni package aggiornate a `0.74.7`.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` per bloccare automaticamente questa famiglia di errori:

- valori `intent` usati nei dataset `customerEducationPages` ma non dichiarati nella union `EducationIntent`;
- mapping mancante tra `EducationIntent` e `SeoSearchIntent`;
- regressioni su literal runtime SEO/GEO non allineati ai contratti TypeScript.
