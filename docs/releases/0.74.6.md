# Release 0.74.6 — Web Build Static Guards Patch 6

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next emerso durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime/build

Errore corretto:

```text
Cannot find module '@clientiaffidabili/shared' or its corresponding type declarations.
```

Intervento:

- `apps/web/package.json` ora dichiara `@clientiaffidabili/shared: workspace:*`.
- `apps/web/tsconfig.json` ora include un path alias di sicurezza verso `../../packages/shared/src/index.ts`.
- `apps/web/next.config.mjs` ora include `transpilePackages: ['@clientiaffidabili/shared']` per rendere sicuri anche futuri import runtime dal package condiviso.
- Versioni package aggiornate a `0.74.6`.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` per bloccare automaticamente questa famiglia di errori:

- file web che importano `@clientiaffidabili/shared` senza dipendenza workspace dichiarata;
- package shared senza nome corretto;
- path alias TypeScript mancante;
- `transpilePackages` mancante nel Next config;
- Dockerfile web senza supporto install/link package shared.
