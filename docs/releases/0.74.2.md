# Release 0.74.2 — Web Build Static Guards Patch 2

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next segnalato su `Stepper` e ampliare il gate statico ai componenti design system che possono generare type error in sequenza durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime

- Corretto il caso segnalato su `apps/web/app/checkout/page.tsx`: `Stepper` ora supporta anche le props legacy `steps` e `currentStep` oltre al contratto typed `items`.
- `Stepper` normalizza internamente `items`/`steps` tramite `normalizeStepperItems`, con `currentStep` 1-based e stati `done/current/todo`.
- `StatusPill` ora supporta sia `label` sia children legacy, evitando il prossimo possibile errore su `<StatusPill>Testo</StatusPill>`.
- `ProgressBar` ora supporta il prop opzionale `max`, già usato dai pannelli wallet/usage, normalizzando il valore in percentuale.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` per controllare anche:

- `Stepper steps/currentStep` legacy;
- `StatusPill` con children senza `label`;
- `ProgressBar max`;
- i controlli già presenti su `StatCard`, `DataTable`, `Alert`, `Checklist`, CSS `end` e plugin Next in `tsconfig`.

## Artifact

- Aggiornato `artifacts/qa/web-build-static-guards-latest.json` con i nuovi conteggi e le nuove famiglie di errore coperte.
