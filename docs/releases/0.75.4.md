# Release 0.75.4 — Test Mode Commerce Visibility

## Obiettivo
Rendere evidente al cliente finale quando l'ambiente è in modalità test e gli acquisti sono disabilitati tramite `ENABLE_CHECKOUT=false`.

## Implementato
- Nuovo helper runtime `apps/web/lib/runtime/commerce-mode.ts`.
- Nuovo componente `TestModeNotice` riutilizzabile sulle pagine pubbliche e checkout.
- Avvisi visibili su homepage, servizi, dettagli servizio, prezzi e checkout.
- CTA pubbliche adattate in modalità test: “Vedi percorso in modalità test”.
- Checkout con pulsante pagamento disabilitato e link di supporto.
- Microcopy esplicito: nessun pagamento reale, nessuna verifica reale, percorso consultabile solo per prova.
- Stili dedicati in `globals.css`.
- QA statico `scripts/qa-test-mode-commerce-visibility.js`.

## Guardrail
La modalità live è attiva solo se `ENABLE_CHECKOUT=true`. In assenza di questa variabile o con valore `false`, l'interfaccia mostra chiaramente la modalità test.
