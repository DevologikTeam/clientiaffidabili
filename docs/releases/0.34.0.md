# Release 0.34.0 — M10-S Fiscalita, Fatturazione e Customer Legal Development

Data: 2026-05-30

## Sintesi

Questa release completa lo sprint di sviluppo M10-S. Introduce il runtime fiscal/legal MVP: profilo fiscale cliente, documenti fiscali manual-assisted, legal pack versionato, accettazioni, audit, UI cliente e admin queue.

## Aggiunto

- `FiscalLegalModule` NestJS.
- Entita `CustomerTaxProfile`, `FiscalDocument`, `LegalDocumentVersion`, `LegalAcceptance`, `FiscalLegalAuditEvent`.
- API customer/admin fiscal/legal.
- Service con snapshot fiscale, hash, legal pack completeness, reason obbligatoria e audit.
- UI `/dashboard/profilo-fiscale` e `/dashboard/legale`.
- UI `/admin/fiscal-legal`.
- Pagine legal pubbliche placeholder.
- QA script `qa-fiscal-legal-development`.

## Decisione MVP

Manual-assisted: nessun invio SDI automatico e testi legal non considerati definitivi fino a revisione professionale.

## QA

Eseguito `node scripts/qa-fiscal-legal-development.js` e suite `for f in scripts/qa-*.js; do node "$f"; done`.
