# Release 0.75.5

## Browser Permission Prompt Guard

Patch per evitare popup browser non richiesti sulle pagine pubbliche, in particolare richieste collegate a passkey/WebAuthn/FedCM/credential management.

### Aggiunto

- Header `Permissions-Policy` restrittivo in `apps/web/next.config.mjs`.
- Autocomplete espliciti nei form login, registrazione e invito.
- QA `scripts/qa-browser-permission-public-guards.js`.
- Documentazione `docs/public-copy/04_BROWSER_PERMISSION_PROMPT_GUARD.md`.

### Nota

Le passkey non sono eliminate come direzione futura, ma non devono attivarsi automaticamente. Qualsiasi integrazione futura dovrà essere dietro click esplicito e area dedicata.
