# Release 0.14.0 — M5-A Provider Integration Analysis

## Sprint completato

M5-A — Provider Integration Analysis

## Cosa include

- Strategia provider Openapi-first.
- Mapping servizi MVP verso provider candidati.
- Provider request lifecycle post-payment.
- Cost tracking e provider cost snapshot.
- Tassonomia errori, retry e fallback.
- Normalizzazione payload ed evidence model.
- Security/privacy/compliance analysis.
- Admin operations provider.
- Readiness checklist per M5-P/M5-S.
- Tipi condivisi provider analysis.
- Costanti backend/frontend di analisi.
- QA antiregressione statico.

## Guardrail

- Nessuna chiamata provider prima del pagamento confermato.
- Nessuna credenziale provider nel frontend.
- Nessun raw payload mostrato al cliente.
- Retry automatico solo se sicuro e idempotente.
- Manual review per servizi paid incerti.
- Report sempre con fonte, data e limiti.
- Production provider bloccata fino a verifica documentazione/credenziali ufficiali.
