# Release 0.38.0 — M12-A API Partner & Reseller Portal Analysis

## Tipo

Sprint di analisi.

## Aggiunto

- Analisi strategica portale partner/reseller.
- Segmentazione partner e packaging.
- Modello revenue, margini, crediti e sconti reseller.
- Analisi API key, scopes, rate limit, idempotenza e webhook.
- Analisi developer experience e documentazione OpenAPI.
- Analisi onboarding/KYB/legal partner.
- Analisi usage ledger, crediti e billing partner.
- Analisi admin operations partner.
- Checklist M12-P/M12-S.
- File TypeScript frontend/backend di analisi.
- QA antiregressione dedicato.

## Decisione

Il portale partner deve partire come canale controllato, manual-approved, sandbox-first e credit-wallet-first. Le API production saranno abilitate solo dopo review tecnica, compliance e contrattuale.

## Non incluso

- Endpoint API partner production reali.
- Payout automatici o revenue share automatico.
- Legal pack partner definitivo.
- Build reale con dipendenze installate.
