# 0.74.13 - Coolify Preflight Dependency Bootstrap Patch

## Obiettivo

Rendere `pnpm qa:coolify-preflight` utilizzabile subito dopo l'estrazione dello ZIP, anche quando `node_modules` non e ancora presente nel checkout locale.

## Fix

- Aggiunto bootstrap dipendenze automatico in `scripts/coolify-preflight.sh`.
- Aggiunto bootstrap dipendenze automatico in `scripts/coolify-preflight.ps1`.
- Il preflight ora esegue `pnpm install --frozen-lockfile=false` se mancano `node_modules/.pnpm`, `apps/api/node_modules/.bin/nest` o `apps/web/node_modules/.bin/next`.
- Aggiunto `SKIP_INSTALL=1` per ambienti CI che installano gia le dipendenze separatamente.
- Rafforzato `qa-coolify-preflight-static-guards.js` per garantire che l'install avvenga prima di `pnpm --filter @clientiaffidabili/api build` e `pnpm --filter @clientiaffidabili/web build`.
- Aggiornata documentazione `docs/deployment/COOLIFY_PREFLIGHT.md`.

## QA

- `node scripts/qa-coolify-preflight-static-guards.js`
- `node scripts/qa-web-build-static-guards.js`
- `node scripts/qa-docker-runtime-static-guards.js`
- `node scripts/qa-api-typeorm-postgres-static-guards.js`
- `node scripts/qa-source-syntax-smoke.js`
- `node scripts/security-secret-scan.js`

## Nota

Il comando Docker reale resta da eseguire nell'ambiente locale/Coolify. Questa patch chiude il blocco locale iniziale `nest non e riconosciuto` dovuto a dipendenze mancanti.
