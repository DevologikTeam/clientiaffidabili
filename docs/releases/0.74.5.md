# Release 0.74.5 — Web Build Static Guards Patch 5

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next emerso durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime/type safety

- Corretto il caso segnalato su `apps/web/components/billing/SubscriptionPlanCard.tsx`: `Checklist` usata con `className`.
- `apps/web/components/ds/Checklist.tsx` ora espone `className?: string` e unisce la classe custom con `ca-checklist`.
- Rafforzata la compatibilita del design system per props `className` gia usate in pagine reali:
  - `Alert`;
  - `Badge`;
  - `KeyValueList`;
  - `PageHero`;
  - `PriceCard`;
  - `ProgressBar`;
  - `SectionHeader`;
  - `StatCard`;
  - `StatusPill`;
  - `Stepper`;
  - `TrustNotice`.
- `Stepper` mantiene compatibilita legacy `steps/currentStep`, `items` readonly-safe e supporto `className`.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` con guard generico per i componenti del design system usati con `className`.

Il gate ora blocca componenti `apps/web/components/ds/*.tsx` quando una pagina li usa con `className` ma il contratto props non espone `className?:` o non eredita da `HTMLAttributes`/`ComponentProps`.

Il gate ora copre anche:

- `Checklist className`;
- className su componenti design-system gia usati in produzione;
- `StatCard` numerico/helper;
- `DataTable` colonne legacy;
- `DataTable` callback render implicit-any;
- `Stepper steps/currentStep`;
- `StatusPill` children;
- `ProgressBar max`;
- `Alert description`;
- `Checklist { label, done }`;
- CSS `end`;
- plugin Next in `tsconfig`;
- cache `tsconfig.tsbuildinfo` non incluse nello ZIP;
- array `readonly/as const` nei component props.
