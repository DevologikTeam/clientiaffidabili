# Release 0.74.4 — Web Build Static Guards Patch 4

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next emerso durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime/type safety

- Corretto il caso segnalato su `apps/web/app/admin/reports/page.tsx`: callback `DataTable` inline con `render: (row) => ...` non contestualmente tipizzata in strict mode.
- Annotate le callback `DataTable render` inline interessate per evitare `Parameter 'row' implicitly has an 'any' type`.
- Estesa la stessa protezione ad altre tabelle che usano colonne inline con callback `render`.
- Corretto refuso nel contratto `apps/web/components/ds/DataTable.tsx`: `ReadonlyReadonlyArray` → `ReadonlyArray`.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` con due nuovi guard:

- blocco di callback `DataTable` non tipizzate, come `render: (row) => ...` o `render: (gate) => ...`;
- blocco di refusi `ReadonlyReadonlyArray` nel contratto `DataTable`.

Il gate ora copre anche:

- `StatCard` numerico/helper;
- `DataTable` colonne legacy;
- `DataTable` callback render implicit-any;
- `Stepper steps/currentStep`;
- `StatusPill` children;
- `ProgressBar max`;
- `Alert description`;

- CSS `end`;
- plugin Next in `tsconfig`;
- cache `tsconfig.tsbuildinfo` non incluse nello ZIP;
- array `readonly/as const` nei component props.
