# Release 0.75.3 — Contact Form Senior UX Review

Questa patch migliora il form contatti pubblico con una revisione da senior UX/full stack.

## Miglioramenti

- form meno largo e più leggibile;
- layout a due colonne con rassicurazione e processo;
- fieldset semantici e hint accessibili;
- copy orientato al cliente finale;
- nuova route Next per inoltrare il form al backend;
- `INTERNAL_API_URL` per chiamate server-side dal web container all'API;
- QA dedicato al form contatti.
