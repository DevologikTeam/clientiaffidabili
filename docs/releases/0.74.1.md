# Release 0.74.1 — Web Build Static Guards Patch

Patch di qualità su M21-S per prevenire regressioni ricorrenti nel build Next/Docker prima del prossimo sprint.

## Fix runtime

- Corretto il caso segnalato su `apps/web/app/admin/provider/page.tsx`: i conteggi passati a `StatCard` vengono stringificati esplicitamente nel punto che aveva bloccato Docker.
- `StatCard` ora accetta `ReactNode` per `value` e `description`, quindi supporta numeri, stringhe e contenuti renderizzabili.
- `StatCard` mantiene `helper` come alias retrocompatibile di `description` per le pagine legacy.
- `apps/web/tsconfig.json` include il plugin Next, evitando mutazioni automatiche durante `next build`.

## Nuovo QA generico

- Aggiunto `scripts/qa-web-build-static-guards.js`.
- Aggiunto script npm `qa:web-build-static-guards`.
- Aggiunto script npm `release:pre-zip-check` per il controllo minimo prima dello ZIP.
- Inserito il nuovo gate nel workflow `.github/workflows/production-qa.yml` prima di lint/typecheck/build.
- Aggiunto artifact `artifacts/qa/web-build-static-guards-latest.json`.

## Errori prevenuti

- `Type 'number' is not assignable to type 'string'` su `StatCard value`.
- `helper` non definito su `StatCard` in pagine legacy.
- `DataTable columns={['...']}` senza compatibilità legacy.
- warning Autoprefixer su `align-items:end` e varianti CSS `end`.
- mutazione automatica del `tsconfig.json` da parte di Next in build Docker.
- `Alert description` e `Checklist { label, done }` non compatibili con i contratti dei componenti DS.
