# Release 0.74.12 — Coolify Preflight Gate & Docker Symlink Fix #38

## Fix #38

Corretto il blocco Docker web runner causato da symlink non idempotente:

```text
ln: /app/node_modules/next: File exists
```

Il Dockerfile ora rimuove solo i symlink rotti prima di creare link verso i package runtime `next`, `react`, `react-dom` e `styled-jsx`.

## Coolify preflight

Aggiunti:

- `scripts/coolify-preflight.sh`;
- `scripts/coolify-preflight.ps1`;
- `scripts/qa-coolify-preflight-static-guards.js`;
- `docs/deployment/COOLIFY_PREFLIGHT.md`;
- script package `qa:coolify-preflight`, `qa:coolify-preflight:ps1`, `qa:coolify-preflight:static-guards`.

Il preflight esegue build pnpm API/web, Docker Compose build no-cache, avvio container, healthcheck e raccolta log.
