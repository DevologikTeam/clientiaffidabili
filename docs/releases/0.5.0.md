## Decisioni prese

- Il funnel pubblico sarà orientato a **decisioni B2B prudenti**, non a elenco API.
- La CTA primaria diventa `Verifica un'azienda`.
- La landing dovrà contenere un selettore per scenario.
- Il report preview diventa asset centrale di conversione.
- Il checkout resta servizio-specifico e richiede conferma uso lecito.
- Le pagine SEO/GEO saranno verticali per intento.
