## Decisioni principali

- I settings sensibili non devono mai essere letti in chiaro da UI o frontend.
- OpenAI deve essere gestito da settings admin con use case consentiti, budget, redaction e error ledger.
- Gli errori operativi devono essere business-correlati, non solo log tecnici.
- IP acquisto e user agent vanno salvati con hash/redaction, accesso limitato e audit.
