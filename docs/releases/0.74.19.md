# Release 0.74.19 - Local Browser Reachable Coolify Preflight

## Obiettivo

Rendere `pnpm qa:coolify-preflight` utile anche come test locale manuale da browser, non solo come simulazione Coolify interna.

## Fix

- Il preflight usa ora `docker-compose.yml` di default, così pubblica le porte `3000` e `3001`.
- Aggiunta modalità strict Coolify-like con `qa:coolify-preflight:strict`.
- Aggiunto `HEALTH_CHECK_MODE=both` in modalità locale: verifica sia endpoint interni ai container sia endpoint host/browser.
- La modalità strict resta su `docker-compose.coolify.yml` e usa health container-only.
- Il compose locale ora passa ENV runtime sicure/default all'API, inclusi `DATABASE_SYNCHRONIZE`, `DATABASE_URL`, `APP_URL`, `API_URL` e feature flag safe-off.
- Aggiornati script Bash e PowerShell.
- Rafforzato `qa-coolify-preflight-static-guards.js`.

## Risultato atteso

Dopo:

```bash
pnpm qa:coolify-preflight
```

il browser locale deve poter aprire:

```text
http://localhost:3000
```

mentre l'API health deve rispondere su:

```text
http://localhost:3001/health
```
