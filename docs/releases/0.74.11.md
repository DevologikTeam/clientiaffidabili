# Release 0.74.11 - Docker Optional Shared Node Modules Patch 11

## Obiettivo

Correggere il build Docker web che falliva nel runner stage durante la copia di un path opzionale non generato da pnpm.

## Fix

- Rimosso `COPY --from=prod-deps /app/packages/shared/node_modules ./packages/shared/node_modules` da `apps/web/Dockerfile`.
- Rimosso `COPY --from=deps /app/packages/shared/node_modules ./packages/shared/node_modules` dai Dockerfile web/API.
- Mantenuto il supporto workspace tramite manifest `packages/shared/package.json`, source package e root/app `node_modules`.
- Rafforzato `qa-docker-runtime-static-guards.js` per bloccare COPY da path opzionali `packages/shared/node_modules`.
- Rafforzato `qa-web-build-static-guards.js` per evitare regressioni sul package condiviso source-only.

## Errore reale coperto

```text
failed to calculate checksum ... "/app/packages/shared/node_modules": not found
```

## Note

Il package `@clientiaffidabili/shared` e' source-only nel runtime corrente: non bisogna assumere che `packages/shared/node_modules` esista negli stage Docker.
