# Release 0.17.0 — M6-A Report Composer Analysis

Data: 2026-05-29

## Sintesi

La release 0.17.0 aggiunge l'analisi del modulo Report Composer. L'obiettivo è trasformare i dati provider normalizzati in report commerciali chiari, prudenti, verificabili e vendibili.

## Aggiunto

- Strategia prodotto report.
- Information architecture report.
- Analisi scoring e decision logic.
- Evidence/source/limits model.
- Copy compliance analysis.
- Data model analysis.
- Admin review analysis.
- Export/download analysis.
- Checklist M6-P/M6-S.
- Tipi/analisi TypeScript lato API e web.
- QA script dedicato.

## Guardrail principali

- Nessun claim assoluto di solvibilità.
- Nessun raw payload provider nel report cliente.
- Report generato solo dopo pagamento e provider completed/manual review.
- Ogni evidenza deve avere fonte, timestamp e limite.
- Snapshot report immutabile.
- Admin review per casi ambigui/compliance-sensitive.
