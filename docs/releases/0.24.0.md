# Release 0.24.0 — M8-P Admin Operations Design

## Sintesi

Questa release aggiunge il blueprint di progettazione della console admin operations: esperienza queue-first, filtri, dettaglio item, azioni sicure, RBAC, reason modal, audit timeline, API contract e handoff allo sviluppo M8-S.

## Guardrail confermati

- Nessuna provider call prima del pagamento confermato.
- Nessun raw payload nelle liste admin.
- Azioni critiche con reason obbligatoria.
- RBAC backend obbligatorio.
- Audit append-only.
- Snapshot prezzo/report immutabili.
