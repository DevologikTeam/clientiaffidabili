# Release 0.25.0 — M8-S Admin Operations Development

## Aggiunto

- `AdminOperationsModule` NestJS;
- entità `AdminWorkItem`;
- entità `AdminActionAudit`;
- controller e service admin operations;
- DTO per azioni admin con reason/idempotency;
- console `/admin/operations`;
- dettaglio `/admin/operations/[id]`;

## Guardrail

- Nessun raw payload nelle liste admin.
- Reason obbligatoria per azioni sensibili.
- Idempotency obbligatoria per azioni ripetibili/costose.
- RBAC backend predisposto.
- Audit append-only.

## Limitazioni

- Auth admin reale non ancora implementata.
- Dati demo controllati per UI runtime.
- Build reale non eseguita offline.
