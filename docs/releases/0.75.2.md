# Release 0.75.2 — Public copy intent type guard fix

Patch correttiva dopo il build Docker/Coolify di v0.75.1.

## Correzione principale

Il cleanup copy pubblico aveva rimosso il valore tecnico `commercial` dal contratto `EducationIntent`, ma `EducationMetaStrip` confrontava ancora `intent === 'commercial'`. Il build Next falliva con:

```text
This comparison appears to be unintentional because the types 'EducationIntent' and '"commercial"' have no overlap.
```

In questa patch:

- `EducationMetaStrip` usa una mappa tipizzata `Record<CustomerEducationPage['intent'], string>`;
- rimossi confronti legacy con `commercial` e `transactional` non presenti nella union runtime;
- resa tipizzata anche la mappa dei temi con `Record<CustomerEducationPage['cluster'], string>`;
- aggiornato il QA pubblico per bloccare regressioni su confronti impossibili tra literal TypeScript e union reali.
