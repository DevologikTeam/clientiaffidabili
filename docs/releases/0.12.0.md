## Decisioni

- Hosted checkout resta il percorso MVP.
- Redirect frontend non conferma mai il pagamento.
- Webhook firmato e idempotente è la fonte di verità.
- Ledger pagamenti è append-only.
- Fatturazione MVP è manual-assisted, pronta per futura integrazione contabile/SDI.
- Admin billing avrà code operative per anomalie, fatture, rimborsi e dispute.
