# Release 0.74.3 — Web Build Static Guards Patch 3

Patch di qualità su M21-S per correggere il nuovo blocco Docker/Next emerso durante `pnpm --filter @clientiaffidabili/web build`.

## Fix runtime/type safety

- Corretto il caso segnalato su `apps/web/app/dashboard/team/page.tsx`: `authRuntimeSnapshot.members` è `readonly` perché il runtime snapshot è dichiarato `as const`, mentre `TeamMembersTable` richiedeva un array mutabile.
- `TeamMembersTable` ora accetta `ReadonlyArray<...>`.
- Allineati allo stesso criterio i componenti web che ricevono liste da snapshot, seed, blueprint o registry:
  - admin operations tables/panels;
  - customer dashboard lists/timelines;
  - fiscal/legal tables;
  - security gate/control tables;
  - SEO CMS page list;
  - catalog pricing comparison;
  - customer education blocks;
  - design system `DataTable`, `Checklist`, `KeyValueList`, `PriceCard`, `Stepper`.

## QA generico rafforzato

Aggiornato `scripts/qa-web-build-static-guards.js` con un guard trasversale: i component prop contracts in `apps/web/components` non devono richiedere array mutabili (`Foo[]`/`Array<Foo>`) quando ricevono dati solo in lettura. Il gate blocca la regressione e richiede `ReadonlyArray<Foo>` o `readonly Foo[]`.

Il gate ora copre anche:

- `StatCard` numerico/helper;
- `DataTable` colonne legacy;
- `Stepper steps/currentStep`;
- `StatusPill` children;
- `ProgressBar max`;
- `Alert description`;
- `Checklist { label, done }`;
- CSS `end`;
- plugin Next in `tsconfig`;
- cache `tsconfig.tsbuildinfo` non incluse nello ZIP;
- array `readonly/as const` nei component props.
