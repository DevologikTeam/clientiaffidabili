# Release 0.64.0 — M18-P Email & Customer Notifications Design

## Added

- Blueprint completo sistema email tecnico cliente/admin.
- Event registry e template registry progettati.
- Email account/security: registrazione, verifica email, reset password, password modificata, remember-me, inviti team.
- Email ordine/pagamento/rimborso: ordine creato, pagamento riuscito/fallito, azione richiesta, rimborso, dispute, abbonamenti e crediti.
- Email report/PDF/documenti: report in lavorazione, documento pronto, PDF via link sicuro, fattura e nota credito.
- Email admin monitor e operations.
- Provider settings e deliverability blueprint.
- API contract per email event, delivery admin e webhook provider.
- Handoff M18-S.

## Guardrail

- Sistema event-driven.
- Nessun invio diretto non tracciato.
- PDF via link sicuro first.
- Allegati PDF solo feature-flagged.
- Token hashati e con scadenza.
- No raw payload, no prompt OpenAI, no API key, no dati carta, no IBAN completo in email o log.
- Bounce/complaint/suppression obbligatori.
- Error ledger integrato.
