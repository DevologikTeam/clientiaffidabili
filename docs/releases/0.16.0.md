# Release 0.16.0 — M5-S Provider Integration Development

- Runtime provider request entities.
- Provider runtime orchestration service.
- Openapi adapter mock/sandbox-ready.

- Provider callback handling.

- Environment template includes provider secrets/config.

## Guardrails

- Provider calls disabled by default.
- Production mappings disabled by default.
- Raw payload never customer-facing.
- Legal-use confirmation required by mapping.
- Provider cost is snapshotted before dispatch.
