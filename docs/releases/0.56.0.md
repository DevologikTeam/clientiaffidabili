# Release 0.56.0 — M15B-S Platform Settings, Bootstrap Admin & Operational Error Ledger Development

## Added
- `SettingsAdminModule` NestJS.
- Settings runtime con default settings per commerce, payments, Openapi, OpenAI ed email.
- Bootstrap primo super admin.
- Kill switch acquisti server-side.
- Secret settings write-only.
- Operational error ledger.
- Buyer IP audit hash/prefix.
- Admin page `/admin/settings`.
- QA dedicato M15B-S.

## Changed
- `BillingService.createCheckoutSession()` controlla `purchases.enabled` prima di creare checkout.
- Billing registra IP audit e errori pagamento nel ledger.
- Provider runtime registra errori provider nel ledger.

## Fixed
