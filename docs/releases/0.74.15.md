# Release 0.74.15 - Docker Builder pnpm CLI Symlink Patch

## Obiettivo
Correggere il fix emerso dal Coolify preflight: `nest build` e `next build` dentro Docker fallivano perché i builder copiavano `node_modules` pnpm da uno stage precedente, lasciando binari CLI che puntavano a target mancanti.

## Fix
- `apps/api/Dockerfile` installa le dipendenze direttamente nello stage `builder` prima del `COPY . .`.
- `apps/web/Dockerfile` installa le dipendenze direttamente nello stage `builder` prima del `COPY . .`.
- Rimossa la dipendenza fragile da `COPY --from=deps /app/node_modules` nel builder.
- Mantenuto lo stage `prod-deps` separato per il runtime production.
- Rafforzato `qa-docker-runtime-static-guards.js` per bloccare builder Docker che copiano `node_modules` pnpm da altri stage e possono rompere i binari `nest`/`next`.

## Evidenza log
Il preflight v0.74.14 falliva con:

```text
Cannot find module '/app/apps/api/node_modules/@nestjs/cli/bin/nest.js'
Cannot find module '/app/apps/web/node_modules/next/dist/bin/next'
```
