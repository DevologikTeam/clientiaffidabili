## Decisioni

- La dashboard è una cabina di regia post-acquisto.
- Gli stati tecnici non devono essere mostrati al cliente.
- Le liste cliente devono essere card-first su mobile.
- Report e download futuri devono essere snapshot-based e auditabili.
- Billing area resta provider-neutral e pronta per Stripe/PayPal subscription future.
- M7-S svilupperà MVP con fixture/mock-safe prima di collegare tutti i dati reali.
