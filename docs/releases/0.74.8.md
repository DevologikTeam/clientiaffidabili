# 0.74.8 - Docker Runtime Static Guards Patch 8

## Obiettivo

Correggere i restart runtime Docker emersi dopo il passaggio del build web/API:

- API: `MODULE_NOT_FOUND: reflect-metadata` durante `node dist/main.js`.
- Web: `MODULE_NOT_FOUND: /app/apps/web/server.js` durante l'avvio del container Next standalone.

## Fix applicati

- `apps/api/Dockerfile` ora usa uno stage `prod-deps` con `pnpm install --prod --filter @clientiaffidabili/api...`.
- Il runner API copia sia root `node_modules` sia `apps/api/node_modules` dallo stage production dependencies, evitando symlink pnpm incompleti provenienti dal builder.
- Il runner API lavora in `/app/apps/api` e avvia `node dist/main.js`.
- `apps/web/Dockerfile` ora supporta entrambi i layout Next standalone:
  - `apps/web/server.js` per layout monorepo;
  - `server.js` per layout standalone root.
- Il runner web copia asset `.next/static` e `public` sia nel path monorepo sia nel path root.
- Impostati `PORT=3000` e `HOSTNAME=0.0.0.0` nel runner web.
- Aggiunto `scripts/qa-docker-runtime-static-guards.js`.
- Collegato il nuovo gate a `qa:docker-runtime-static-guards` e `release:pre-zip-check`.
