# 43 — Billing Portal UI Implementation

Sono stati aggiunti componenti customer/admin per piani, provider, wallet, refund policy e ledger.

## Route
- `/dashboard/abbonamento` per area cliente abbonamenti/crediti.
- `/admin/billing/subscriptions` per vista admin piani e wallet.
- `/admin/billing/refunds` per rimborsi, dispute e ledger.

La UI evita promesse illimitate e spiega sempre stato, motivo e prossima azione.
