# Error insights runtime

Gli error insights sono aggregazioni business-oriented. Non sostituiscono l'Operational Error Ledger.

## Aree monitorate

- pagamenti;
- rimborsi/dispute;
- Openapi/provider;
- OpenAI;
- email;
- checkout;
- report.

## Regola

L'analytics mostra impatto e priorità, il ledger contiene dettaglio operativo e audit.
