# 06 — Growth Dashboard and KPI Analysis

## Dashboard MVP

La dashboard growth deve rispondere a cinque domande:

1. Da dove arrivano utenti e lead?
2. Quali pagine/guide generano azioni?
3. Quali servizi vendono e con che margine?
4. Dove si blocca il funnel?
5. Quali errori generano rimborsi/supporto?

## Sezioni dashboard

### Executive snapshot

- visite pubbliche;
- lead;
- checkout avviati;
- pagamenti confermati;
- ricavi netti;
- margine stimato;
- refund rate;
- error rate operativo.

### SEO/GEO performance

- top guide per visite;
- top guide per CTA;
- top guide per lead;
- cluster più performanti;
- pagine da aggiornare;
- pagine non indicizzabili o non pubblicate.

### Funnel conversion

- page view → CTA click;
- CTA click → checkout;
- checkout → pagamento;
- pagamento → report;
- report → repeat purchase.

### Revenue and margin

- ricavi per servizio;
- margine per servizio;
- costo provider stimato/reale;
- fee pagamento;
- refund impact;
- subscription/credit revenue.

### Operations impact

- payment failures;
- provider failures;
- OpenAI failures;
- email failures;
- webhook failures;
- support tickets per categoria;
- errori risolti/non risolti.

## KPI da evitare

- vanity metrics isolate;
- tempo medio pagina come KPI assoluto;
- numero di pagine pubblicate senza qualità/conversione;
- traffico non qualificato come successo.
