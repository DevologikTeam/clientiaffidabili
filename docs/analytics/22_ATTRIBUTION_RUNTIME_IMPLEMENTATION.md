# Attribution runtime implementation

L'attribution snapshot usa tre blocchi:

- first touch;
- last touch;
- content assist.

Il sistema vieta campi personali e salva solo dati utili a capire la relazione tra contenuti, CTA, checkout, lead e pagamento.

## MVP

- first-touch e last-touch interni;
- content assist per guide SEO/GEO;
- nessun fingerprinting;
- nessun IP in chiaro;
- nessun dato personale.
