## UX

La dashboard deve parlare in modo operativo:

- cosa sta funzionando;
- cosa blocca vendite;
- quale pagina migliorare;
- quale errore correggere;
- quale servizio è sostenibile;
- quale canale genera margine.

Non deve sembrare una dashboard tecnica di log.
