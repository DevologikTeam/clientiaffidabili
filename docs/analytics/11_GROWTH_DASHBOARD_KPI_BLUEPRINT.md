# 11 — Growth Dashboard KPI Blueprint

## Dashboard admin

Route proposta: `/admin/analytics`.

## Sezioni

### 1. Executive KPI

- Visitatori/sessioni pubbliche aggregate.
- Lead creati.
- Checkout iniziati.
- Pagamenti completati.
- Conversion rate lead.
- Conversion rate checkout.
- Ricavi netti.
- Margine stimato.
- Rimborsi e dispute.
- Errori critici.

### 2. Funnel

Fasi:

1. pagina pubblica vista;
2. guida vista;
3. CTA cliccata;
4. servizio visto;
5. checkout iniziato;
6. pagamento completato;
7. provider completed;
8. report pronto;
9. report visto/scaricato.

### 3. SEO/GEO

- Guide pubblicate.
- Guide con lead assistiti.
- Guide con checkout assistiti.
- Query Search Console future.
- Impression/click/CTR/posizione media future.
- Pagine da migliorare.

### 4. Revenue and margin

- Ricavi per servizio.
- Provider cost stimato/reale.
- Payment fee stimata/reale.
- Margine per servizio.
- Refund impact.

### 5. Error insights

- Errori per categoria.
- Errori che bloccano checkout.
- Errori provider che richiedono retry.
- Errori email che bloccano PDF/report.
- Errori OpenAI futuri.

## KPI non ammessi

- Profilazione individuale marketing.
- Dati sensibili per utente.
- Nomi soggetti verificati.
- Raw error stack in dashboard growth.
