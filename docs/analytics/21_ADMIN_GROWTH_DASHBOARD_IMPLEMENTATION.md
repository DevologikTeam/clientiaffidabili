# Admin growth dashboard implementation

La dashboard `/admin/analytics` fornisce una vista iniziale su:

- KPI executive;
- funnel conversione;
- SEO/GEO performance;
- error insights;
- guardrail privacy-safe.

La versione iniziale è scaffold: mostra struttura, copy, componenti e future fonti dati. Il collegamento a dati reali sarà completato con build/test runtime e aggregazioni periodiche.
