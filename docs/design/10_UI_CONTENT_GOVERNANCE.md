# UI Content Governance

## 1. Tono di voce

ClientiAffidabili.it deve parlare come un consulente operativo: chiaro, prudente, utile.

Non deve sembrare:

- un portale burocratico;
- un catalogo tecnico di API;
- un servizio investigativo aggressivo;
- un prodotto che promette certezze assolute.

## 2. Formula copy consigliata

Per ogni blocco operativo usare:

1. Stato.
2. Motivo.
3. Impatto.
4. Prossima azione.

Esempio:

> Verifica completata. I dati principali risultano coerenti con le fonti consultate. Puoi scaricare il report o attivare il monitoraggio se il rapporto è continuativo.

## 3. Parole da preferire

- verifica;
- affidabilità;
- segnali;
- fonti consultate;
- dati disponibili;
- monitoraggio;
- rapporto commerciale;
- prossima azione;
- uso lecito;
- report.

## 4. Parole da evitare nella UI cliente

- endpoint;
- payload;
- provider response;
- tenant;
- adapter;
- scraping;
- scoring garantito;
- blacklist;
- soggetto pericoloso;
- certezza assoluta;
- compliance totale.

## 5. CTA approvate

| Contesto | CTA |
|---|---|
| Landing | `Verifica un'azienda` |
| Servizio | `Avvia questa verifica` |
| Checkout | `Conferma e paga in sicurezza` |
| Dashboard | `Apri report` |
| Report | `Scarica report PDF` |
| Monitoraggio | `Attiva monitoraggio` |
| Errore dato | `Correggi dati inseriti` |

## 6. Microcopy legale prudente

Da usare nei report:

> Il report è generato sulla base delle fonti disponibili al momento della richiesta. Non costituisce garanzia assoluta né sostituisce una valutazione professionale o legale.

Da usare nel checkout:

> Confermando la richiesta dichiari di avere una finalità lecita e coerente con il servizio selezionato.
