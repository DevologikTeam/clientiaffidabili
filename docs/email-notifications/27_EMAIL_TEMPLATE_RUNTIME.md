# Email template runtime

I template partono dal registry `email-template.registry.ts` e vengono renderizzati da `EmailRendererService`.

## Template MVP

- verifica email;
- recupero password;
- ricordami/dispositivo persistente;
- pagamento riuscito;
- pagamento fallito;
- report pronto;
- PDF report pronto.

I prossimi template devono seguire lo stesso modello e dichiarare variabili consentite.
