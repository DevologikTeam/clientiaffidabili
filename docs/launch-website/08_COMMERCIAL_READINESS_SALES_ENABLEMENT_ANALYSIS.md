# 08 — Commercial Readiness and Sales Enablement Analysis

## Obiettivo

Prima del lancio il sito deve essere supportato da materiali commerciali coerenti con il prodotto reale.

## Materiali necessari

- pitch breve homepage;
- pitch commerciale per PMI;
- pitch partner/API;
- FAQ vendita;
- objection handling;
- one-pager PDF futuro;
- esempio report demo isolato;
- script demo commerciale;
- email onboarding post-acquisto;
- email follow-up carrello/checkout se implementata;
- policy rimborsi spiegata in modo umano.

## Obiezioni commerciali prioritarie

1. "Perche' dovrei pagare se posso fare una visura?"
2. "Il report mi dice se paghera'?"
3. "Quanto sono aggiornati i dati?"
4. "Posso usarlo per decidere se vendere a credito?"
5. "Cosa succede se il report e' incompleto?"
6. "Come funziona il rimborso?"
7. "Posso usarlo via API?"
8. "Posso farlo usare al mio team?"

## Readiness commerciale P0

- homepage con messaggio chiaro;
- catalogo/prezzi coerenti;
- checkout senza sorprese;
- legal/limiti raggiungibili;
- report example non fake in produzione, ma demo isolata;
- supporto visibile;
- CMS pronto per pagine education.
