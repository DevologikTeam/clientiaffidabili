# 04 — Copy, Value, Guarantee and Trust Analysis

## Garanzia comunicabile

ClientiAffidabili.it puo' comunicare una **garanzia operativa**:

- prezzo visibile prima dell'acquisto;
- dati richiesti chiari;
- report con fonti e data richiesta;
- limiti esplicitati;
- supporto in caso di problemi;
- rimborso possibile se il servizio non e' stato ancora consumato dal provider, secondo policy;
- nessuna chiamata provider prima di pagamento confermato o credito riservato.

## Garanzia non comunicabile

Non comunicare mai:

- garanzia di pagamento;
- solvibilita' certa;
- assenza totale di rischio;
- verdetto legale definitivo;
- promessa di completezza assoluta dei dati.

## Claim approvati

- "Riduci l'incertezza prima di vendere a un nuovo cliente.";
- "Verifica segnali disponibili e limiti prima di decidere.";
- "Ricevi un report chiaro, con fonti e data della richiesta.";
- "Prezzi e tempi visibili prima dell'acquisto.";
- "Utile per una valutazione preliminare, non sostituisce consulenza legale o finanziaria.".

## Claim bloccati

- "cliente affidabile al 100%";
- "pagamento garantito";
- "rischio zero";
- "scopri tutto su qualsiasi persona";
- "report infallibile";
- "evita ogni insoluto".

## Obiezioni da trattare nel sito

| Obiezione | Risposta copy |
|---|---|
| "Mi basta una visura?" | La visura e' utile, ma non sempre basta per leggere segnali commerciali e limiti operativi. |
| "Il report garantisce che paghera'?" | No. Aiuta a ridurre l'incertezza, non elimina il rischio. |
| "Da dove vengono i dati?" | Il report indica fonti, data richiesta e limiti di aggiornamento. |
| "Posso chiedere rimborso?" | Dipende dallo stato: prima del consumo provider e' piu' semplice; dopo report generato serve review. |
| "E' lecito usarlo?" | Il checkout richiede conferma di uso lecito e finalita' commerciale legittima. |
