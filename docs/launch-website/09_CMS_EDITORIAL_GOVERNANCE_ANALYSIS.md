# 09 — CMS Editorial Governance Analysis

## Stato corrente

Il progetto include gia' un CMS admin per pagine SEO/GEO con editor React Tiptap, stati bozza/review/pubblicato/archiviato e guardrail claim.

## Evoluzione richiesta per M14-P/M14-S

Il CMS deve diventare parte del launch website:

- pagine pubblicate incluse in sitemap;
- canonical automatico;
- metadata obbligatori;
- checklist SEO/GEO prima della pubblicazione;
- anteprima snippet;
- anteprima answer box;
- controllo claim vietati;
- internal link suggeriti;
- storico versioni;
- noindex automatico per draft/review.

## Workflow editoriale consigliato

1. Admin crea bozza.
2. Compila intent, titolo, descrizione, answer box, contenuto e CTA.
3. Il sistema segnala mancanze SEO/GEO.
4. La pagina passa in review.
5. Un admin approva con reason.
6. La pagina viene pubblicata e appare in sitemap.
7. Ogni modifica successiva crea una nuova versione.

## Guardrail copy CMS

Bloccare o richiedere review per:

- claim assoluti;
- promesse finanziarie;
- parole investigative su persone fisiche;
- contenuti legali non validati;
- garanzie non supportate dalla policy;
- prezzi non coerenti con catalogo.
