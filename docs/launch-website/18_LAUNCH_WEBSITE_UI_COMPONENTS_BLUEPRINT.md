## Stati obbligatori

- loading;
- empty;
- draft/review/published;
- noindex warning;
- blocked claim warning;
- schema mismatch warning;
- published success;
- rollback required.

## Design rules

- CTA primaria sempre unica sopra la piega;
- secondary CTA informativa, non in competizione;
- notice sui limiti sempre visibile prima del checkout;
- trust copy breve;
- mai usare warning/rosso per vendere paura;
- mobile-first per guide e checkout entry.
