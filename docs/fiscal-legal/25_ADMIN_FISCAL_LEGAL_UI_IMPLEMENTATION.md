# Admin fiscal/legal UI

La pagina `/admin/fiscal-legal` espone una coda sintetica per:

- profili fiscali da verificare;
- fatture/documenti da preparare;
- note credito;
- legal pack da pubblicare;
- azioni con reason obbligatoria.

## Principi UX

- Mostrare motivo, impatto e prossima azione.
- Non mostrare raw payload provider.
- Non mostrare dati sensibili non necessari in lista.
- Ogni azione critica deve lasciare audit.
