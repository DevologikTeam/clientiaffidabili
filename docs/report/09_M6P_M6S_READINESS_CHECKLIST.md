# M6-P / M6-S readiness checklist

## Gate per M6-P

- [ ] Disegnare data model Report/Section/Evidence/Review.
- [ ] Disegnare template report web.
- [ ] Disegnare score model versionato.
- [ ] Disegnare report status lifecycle.
- [ ] Disegnare admin review queue.
- [ ] Disegnare copy deck report.
- [ ] Disegnare PDF/export strategy.
- [ ] Disegnare API contract report.
- [ ] Disegnare QA copy/compliance.

## Gate per M6-S

- [ ] Implementare entity Report aggiornate.
- [ ] Implementare ReportComposerService.
- [ ] Implementare section/evidence builder.
- [ ] Implementare score explainability.
- [ ] Implementare report page reale.
- [ ] Implementare admin review queue.
- [ ] Implementare report ready state.
- [ ] Implementare QA antiregressione report.
- [ ] Preparare export PDF o placeholder sicuro.

## Guardrail bloccanti

- [ ] Nessun report senza ordine pagato.
- [ ] Nessun raw payload provider visibile al cliente.
- [ ] Nessun claim assoluto di solvibilità.
- [ ] Nessun report senza fonti/timestamp minimi.
- [ ] Nessun dato personale non necessario nel report.
- [ ] Nessuna modifica retroattiva a report pubblicati.
- [ ] Audit log per generazione, review, pubblicazione e download.
