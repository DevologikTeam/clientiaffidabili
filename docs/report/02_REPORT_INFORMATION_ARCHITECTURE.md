# Report information architecture

## Struttura standard report

1. **Header report**
   - Nome verifica.
   - Soggetto verificato.
   - Data richiesta.
   - Stato report.
   - ID ordine/report.

2. **Executive summary**
   - Livello di attenzione.
   - Score descrittivo se disponibile.
   - Messaggio sintetico.
   - Prossima azione consigliata.

3. **Segnali principali**
   - Segnali favorevoli.
   - Segnali da verificare.
   - Segnali critici.

4. **Dati identificativi**
   - Ragione sociale.
   - Partita IVA/codice fiscale aziendale quando disponibile.
   - Sede legale.
   - Stato attività.
   - Forma giuridica.

5. **Affidabilità e continuità operativa**
   - Stato impresa.
   - Eventuali negatività/protesti/pregiudizievoli se incluse nel prodotto acquistato.
   - Indicatori credito se inclusi.

6. **Compliance/KYB**
   - PEP/sanctions/adverse media solo se prodotto acquistato e fonte disponibile.
   - Titolare effettivo solo se previsto da servizio e legittimo interesse.

7. **Fonti e evidenze**
   - Fonte dato.
   - Timestamp fonte.
   - Timestamp richiesta.
   - Limiti.

8. **Limiti del report**
   - Dati disponibili al momento della richiesta.
   - Possibili ritardi fonti ufficiali.
   - Nessuna garanzia su eventi futuri.

9. **Azioni consigliate**
   - Procedi con cautela standard.
   - Richiedi documentazione integrativa.
   - Applica pagamento anticipato.
   - Attiva monitoraggio.
   - Esegui verifica avanzata.

## Sopra la piega

Le prime informazioni devono rispondere subito a:

- Chi ho verificato?
- Che livello di attenzione emerge?
- Perché?
- Cosa faccio adesso?

## Sezioni collassabili

Le sezioni tecniche devono essere collassabili:

- dettaglio evidenze;
- raw-like normalized fields;
- note fonti;
- timeline provider;
- limiti estesi.

## Navigazione report

Per report lunghi è previsto un indice laterale o sticky:

- Sintesi;
- Segnali;
- Dati azienda;
- Fonti;
- Limiti;
- Azioni.

## Responsive

Mobile-first:

- score e sintesi in alto;
- card verticali;
- tabelle trasformate in key/value;
- CTA sticky solo se non invasiva;
- download/report history in area secondaria.
