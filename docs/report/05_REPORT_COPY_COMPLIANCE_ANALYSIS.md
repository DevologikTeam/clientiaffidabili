# Report copy and compliance analysis

## Tono del report

Il tono deve essere:

- chiaro;
- sobrio;
- istituzionale;
- operativo;
- non allarmistico;
- non investigativo;
- non diffamatorio;
- non predittivo in modo assoluto.

## Copy pattern consigliati

### Sintesi positiva

> Non emergono segnali critici tra le informazioni disponibili per questa verifica. Procedi con cautela standard e conserva il report come supporto alla decisione.

### Sintesi con attenzione media

> Sono presenti alcuni elementi da approfondire prima di procedere. Valuta documentazione integrativa, condizioni di pagamento più prudenti o una verifica avanzata.

### Sintesi con attenzione alta

> Sono presenti segnali che richiedono cautela rafforzata. Prima di procedere, verifica i dettagli con il tuo consulente o richiedi documentazione aggiuntiva al soggetto interessato.

### Dati insufficienti

> Le fonti disponibili non consentono una sintesi completa. L'assenza di dati non equivale automaticamente ad assenza di criticità.

## Frasi vietate

- “Cliente sicuro”.
- “Azienda affidabile al 100%”.
- “Pagherà regolarmente”.
- “Non ci sono rischi”.
- “Soggetto insolvente” se non supportato da fonte specifica e formulazione prudente.
- “Black list” o linguaggio stigmatizzante.
- “Indagine” in contesti non autorizzati.

## Microcopy per limiti

> Questo report è basato sui dati disponibili al momento della richiesta e sulle fonti indicate. Non rappresenta una garanzia di pagamento, solvibilità futura o assenza di eventi successivi.

## Microcopy per fonti incomplete

> Alcune informazioni non risultano disponibili per il servizio acquistato o per le fonti consultate. Puoi acquistare una verifica avanzata oppure richiedere una review assistita.

## Microcopy per amministrazione interna

Lato admin si può essere più tecnico, ma sempre ordinato:

- “Provider response requires review”.
- “Evidence missing source timestamp”.
- “Score blocked by compliance-sensitive field”.
- “Report cannot be published until operator approval”.

Non mostrare questi messaggi nel report cliente.
