# v0.75.0 — Public Trust Copy, Logo & Layout Polish

## Scope

Patch prodotto/copy sulle superfici pubbliche viste negli screenshot: home, servizi, prezzi e topbar.

- Logo kit sostituito in `apps/web/public`.
- Header aggiornato con mark + wordmark testuale per rendere visibile il brand anche se l’asset contiene molto spazio bianco.
- Homepage riscritta in chiave cliente finale.
- Pagina servizi riscritta in chiave problema → verifica → decisione.
- Pagina prezzi corretta: rimossi “da” dai prezzi dei singoli pacchetti.
- Messaggi tecnici/interni spostati fuori dal copy pubblico.
- Aggiunto documento di analisi competitor/copy.
- Aggiunto QA statico contro regressioni copy pubbliche.

## Note

La patch non cambia logiche di pagamento, provider, report o runtime. Interviene su percezione, fiducia, chiarezza e presentazione.
